# Blueprint

Owns the city intent: what kind of city is being built, where districts belong, how the city expands, and which constraints cannot be violated.

Use this area for master plans, district character, build phases, site constraints, resilience targets, and metrics that judge whether the generated city feels plausible.

`cityBlueprint.ts` contains the current executable seed for district rules, named public spaces, waterways, and planting assumptions.
