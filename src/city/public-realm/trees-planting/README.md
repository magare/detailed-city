# Trees Planting

Owns species, canopy spread, tree pits, planters, soil volume, seasonal color, and green corridors.

Tree plantings are generated as `tree-planting` objects for parks, the detailed street slice, and citywide street profiles that expose a tree zone. Street trees attach to parent sidewalks, detailed slice trees also reference curb zones, and every tree carries canopy class/spread, soil volume, seasonal color, green-corridor role, and heat/ecology scores for validation and diagnostics.
